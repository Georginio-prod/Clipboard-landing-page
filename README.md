## 📌 Présentation

Landing page d'une application de **presse-papiers synchronisé** (Clipboard). Version **Tailwind CSS** ; le même défi a aussi été intégré en **Sass** dans [Clipboard-landing](https://github.com/Georginio-prod/Clipboard-landing) pour comparer les deux approches.

Réalisé en **HTML sémantique + Tailwind CSS**, servi par **Vite** (rechargement à chaud et build optimisé),
sans framework JavaScript : l'objectif est la maîtrise du CSS et du responsive.

## ✨ Fonctionnalités

- Héros avec logo, accroche et boutons « Download for iOS / Mac ».
- Section « Keep track of your snippets » : image d'ordinateur débordante + liste de 3 avantages.
- Section « Access Clipboard anywhere » avec illustration d'appareils.
- Grille de 3 fonctionnalités avec icônes, logos de clients (Google, IBM, Microsoft, HP, Vector Graphics).
- Appel à l'action final et footer avec liens et réseaux sociaux.

## 🛠️ Stack

| Élément | Détail |
|---|---|
| Structure | HTML5 sémantique |
| Styles | Tailwind CSS 3 (config personnalisée), PostCSS, Autoprefixer |
| Outils | Vite 5 (dev server + build) |
| Maquette | Frontend Mentor — mobile 375px / desktop 1440px |

## 📁 Structure

```
Clipboard-landing-page/
├── index.html              # Toute la structure de la page
├── style.css               # Directives Tailwind + styles complémentaires
├── main.js                 # Importe la feuille de style (point d'entrée Vite)
├── tailwind.config.js      # Couleurs / polices du style guide
├── postcss.config.*        # Tailwind + Autoprefixer
├── public/                 # Images, icônes, fonds de la maquette
└── package.json
```

## 🚀 Installation & lancement

```bash
git clone https://github.com/Georginio-prod/Clipboard-landing-page.git
cd Clipboard-landing-page
npm install
npm run dev          # http://localhost:5173
```

`npm run build` génère le site statique dans `dist/` ; `npm run preview` le prévisualise.

## 🌐 Déploiement

Déployé sur **Vercel** (framework Vite, sortie `dist/`). Aucune variable d'environnement.

## 🎓 Ce que ce projet démontre

Fonds décoratifs différents mobile / desktop, grilles de fonctionnalités, boutons avec ombres colorées, structure d'une landing page complète.
